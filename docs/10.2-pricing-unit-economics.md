# 8. Mercado Pago Assumption

Para planificación financiera se adopta:

```text
PAYMENT_GATEWAY_EFFECTIVE_RATE
=
10%
```

Debe tratarse como:

```text

```

y no como una regla técnica permanente.

# 9. Payment Gateway Formula

```text
gatewayFee =
grossRevenue × gatewayRate
```

Entonces:

```text
netPaymentRevenue =
grossRevenue - gatewayFee
```

Para una suscripción:

```text
USD 7.99 × 10%
=
USD 0.799
```

Neto:

```text
USD 7.99
-
USD 0.799
=
USD 7.191
```

Aproximadamente:

```text
USD 7.19
```

---

# 10. Desired Net Price Formula

Cuando se quiere conservar un neto determinado después del gateway:

```text
grossPrice =
desiredNet
/
(1 - gatewayRate)
```

Ejemplo:

```text
desiredNet:
USD 6.99

gateway:
10%
```

```text
6.99 / 0.90
=
7.766...
```

Por eso:

```text
USD 7.99
```

es un precio comercial razonable.

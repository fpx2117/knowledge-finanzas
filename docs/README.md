# KnowFinanzas - Metas

## 1. Objetivo

Permitir definir objetivos de ahorro medibles y mostrar progreso, monto faltante y esfuerzo requerido.

## 2. Ruta

`/goals`

## 3. Subvistas

- Todas.
- Activas.
- Completadas.

Los tipos de meta deben ser atributos, no submenus.

## 4. Crear meta

Campos:
- nombre;
- monto objetivo;
- monto inicial opcional;
- fecha objetivo opcional;
- tipo;
- nota.

## 5. Tarjeta de meta

- nombre;
- progreso;
- ahorrado;
- objetivo;
- faltante;
- fecha objetivo;
- estado.

## 6. Detalle

- Progreso historico.
- Aportes.
- Monto faltante.
- Ritmo necesario.
- Fecha estimada segun ritmo actual, solo cuando exista evidencia suficiente.

## 7. Acciones

- Crear.
- Editar.
- Registrar aporte.
- Retirar aporte.
- Pausar.
- Completar.
- Archivar.

## 8. Tipos sugeridos

- Ahorro general.
- Fondo de emergencia.
- Compra.
- Viaje.
- Cancelacion de deuda.
- Otro.

## 9. Estados

- Sin metas.
- Meta sin fecha.
- Meta atrasada.
- Meta completada.
